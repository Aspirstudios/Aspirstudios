## About

**Aspir Studios** is the independent software development label of **Bruno** — also known as **Aurora** — GitHub: [@Aspirstudios](https://github.com/Aspirstudios).

Developing since **2022**, the studio focuses on practical, privacy-conscious, and user-oriented software: desktop utilities, networking tools, music players, and experimental system builds. The approach is deliberate and consistent: build useful things, keep them focused, and ship them.

- **Focus areas:** Desktop utilities, networking, privacy, automation
